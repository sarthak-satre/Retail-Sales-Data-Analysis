# Retail Sales Data Analysis

## Project Overview
This project focuses on analysing retail sales data using Python to identify business trends, evaluate sales performance, and generate meaningful business insights.

## Tools & Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset Information
- 1,000 raw retail sales records
- 13 original columns
- Indian retail sales data

## Project Objectives
- Clean and prepare raw retail sales data.
- Analyse product and category performance.
- Identify sales trends across cities and regions.
- Understand customer payment preferences.
- Evaluate order delivery and cancellation rates.

## Data Cleaning
- Checked and handled missing values.
- Removed duplicate records.
- Corrected data types.
- Standardised text values.
- Removed invalid quantities, prices, and discounts.

## Analysis Performed
- Total sales and net sales.
- Product-wise and category-wise sales.
- City-wise and region-wise sales.
- Monthly sales trends.
- Payment method analysis.
- Order status analysis.
- Delivery and cancellation rate analysis.

## Key Business Insights
- March recorded the highest monthly net sales.
- UPI was the most frequently used payment method.
- Approximately 71.75% of orders were delivered.
- The cancellation rate was approximately 8.10%.

## Conclusion
This project demonstrates the use of Python for data cleaning, exploratory data analysis, and business insight generation. The analysis helps understand retail sales performance.
